## 第二阶段：整体 UI/UX 视觉交互设计

### 视觉风格
**温暖治愈系** - 采用柔和的渐变、圆角卡片、轻阴影，营造温暖、亲切的氛围

### 配色方案
- **主题色**：#FF6B6B（温暖橙红，象征善意与温暖）
- **辅助色**：#FFA07A（柔和橙）、#FFE4E1（浅粉）
- **背景色**：页面 #F7F8FA / 卡片 #FFFFFF
- **文本色**：主要 #1A1A1A / 次要 #666666 / 辅助 #999999
- **边框色**：#E8E8E8
- **功能色**：成功 #52C41A / 警告 #FAAD14 / 错误 #FF4D4F

### 设计规范
- **间距系统**：8rpx网格系统（16rpx/24rpx/32rpx/48rpx）
- **圆角设计**：卡片16rpx、按钮48rpx（全圆角胶囊）、小元素8rpx
- **阴影设计**：卡片 0 2rpx 12rpx rgba(0,0,0,0.08)、浮层 0 4rpx 16rpx rgba(0,0,0,0.1)
- **字体层级**：标题36rpx/副标题30rpx/正文28rpx/辅助24rpx
